# AI Workflow

## AI Assistance Goals
- Use AI for generating boilerplate code (e.g., queue setups, boilerplate REST endpoints).
- AI code reviews for complex asynchronous logic.
- Documentation generation based on defined APIs.

## Prompts & Guidelines
- **Iterative Development**: Develop strictly **one feature at a time**. Do not attempt to build multiple complex components in a single prompt.
- Keep requests focused on single domains (e.g., "Implement the BullMQ retry mechanism for web push").
- Ensure the AI understands Notica is NOT a standard CRUD app, but an infrastructure platform focusing on resilience and observability.
