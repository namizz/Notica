# Notica Portfolio Images

This directory contains portfolio-ready images generated from the real Notica
application using a disposable demo tenant.

Expected outputs:

1. `01-dashboard-projects.png` — projects and API-key management
2. `02-system-architecture.png` — implementation-based architecture graphic
3. `03-realtime-console.png` — live notification processing activity
4. `04-delivery-logs.png` — delivery history and attempt inspection
5. `05-developer-docs.png` — API and SDK integration documentation
6. `06-2fa-security.png` — QR-based two-factor authentication setup

The QR code and manual secret in image 6 are deliberately redacted before
capture. All displayed users, email addresses, projects, and notification
events are dummy portfolio data.
